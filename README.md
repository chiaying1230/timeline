# 智能障礙歷史年表

獨立的臺灣智能障礙歷史閱讀網站，涵蓋 1962–2024 年的 50 件精選事件，以及 738 篇剪報的整理資料。

讀者包括一般大眾、學生、特教相關人員與智能障礙者本人。主線是「沿時間看發生了什麼」。

## 使用

開啟 `index.html` 即可閱讀。完整的錄音跳轉、進度保存與連結功能，建議透過本機預覽或靜態網站空間使用。

```text
python serve.py --port 8895
```

接著開啟 `http://127.0.0.1:8895/`。此網址僅供這台電腦使用；對外分享須先將網站放到可存取的網頁空間。

## 新版功能

- 先選年代與類型，再開始閱讀；設定時即顯示件數、年代範圍與第一件事件。
- 橫向、等距、按時間排列；事件只先顯示年份、類型與標題。介紹原地展開，可以同時開多件。
- 年代捷徑、目前位置提示，以及可搜尋年份、標題與內文的事件目錄；年代列會跟隨閱讀位置，讓目前年代保持可見。
- 可切換直式清單；提供易讀介紹與整體大字模式。
- 照片、剪報、錄音分開切換；支援圖片放大、錄音調速、逐字稿跳轉與離開時暫停。
- 此瀏覽器保存進度；「繼續上次閱讀」和閱讀連結會恢復篩選、事件與展開狀態。
- 738 篇剪報可獨立搜尋；放寬剪報範圍不改動年表篩選。
- 鍵盤焦點、語意化表單、對話框、減少動態與手機窄螢幕支援。

介面、網站檔案、建置流程與瀏覽器儲存鍵皆獨立。沒有其他展區、舊站說明或舊專案的回連。

## 資料與內容限制

保留既有 50 件精選事件與 738 篇剪報資料。精選包含 18 件重大事件、15 件剪報、9 件研究、8 件人數里程碑。篩選不會把更多剪報加入年表。

同年依已知日期排序，僅知年份的放在該年最後；間距不代表經過的年數。六類事件混排，分類以文字與顏色共同辨識。

易讀介紹為待審閱草稿，尚未經自我倡議者實測。照片、剪報圖片和英文合成錄音皆標為示例，不是歷史原件。沒有根據剪報標題補寫新聞全文。計畫資訊、授權與引用格式仍需內容方確認。

## 維護與發布檔案

修改 `source/src-reader/` 後執行：

```text
python source/build.py
node --test tests/reader-model.test.cjs
```

建置只輸出獨立年表。發布時需要 `index.html`、`icon.svg`、`.nojekyll` 與整個 `assets/` 資料夾。

`source/data.json`、`source/events.json` 為資料；`source/data.js`、`source/events-base.js` 整理資料；`source/easy.js` 為易讀草稿；`source/reader-media.json` 設定附件。已附全部必要來源，不依賴另一個專案的路徑。

字型載入失敗時會使用裝置字型。進度保存在本機瀏覽器，不上傳伺服器；外部字型請求不含閱讀紀錄。

驗證詳見 `qa/checks.md`。這是獨立網站版本；本機預覽不等於對外發布。
