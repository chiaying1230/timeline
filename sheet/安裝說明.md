# 年表試算表：安裝與使用

## 先知道：檔案算誰的容量

- 佔雲端容量的是**照片與錄音檔**。試算表本身幾乎不佔；YouTube 影片不佔；網站本身不在雲端硬碟上。
- 雲端硬碟的容量算在**檔案擁有者**身上。在一般的共用資料夾裡，誰上傳，檔案就是誰的、算誰的容量——即使資料夾是別人建立的。
- 所以這份工具的做法是：由**容量要被使用的那個帳號**（以下稱「擁有者」，例如老闆）安裝並部署表單。其他人透過**表單網址**上傳，檔案一律歸擁有者、存進擁有者的雲端硬碟。
- 如果有人不經表單、自己把檔案拖進共用資料夾再貼連結，網站一樣能顯示，只是那個檔案算上傳者自己的容量。

## 擁有者做一次（約 15 分鐘）

用要提供容量的 Google 帳號操作。

1. **取得試算表**
   - 已有同事建好的試算表：打開它 →「檔案 → 建立副本」。程式會一起複製，跳到第 3 步。
   - 從頭開始：新增一份空白 Google 試算表，做第 2 步。
2. **貼上程式**：「擴充功能 → Apps Script」。把 `Code.gs` 的內容全部換成本資料夾的 `Code.gs`；按「檔案」旁的 **＋ → HTML**，檔名輸入 `Form`，內容全部換成本資料夾的 `Form.html`。儲存。
3. 回到試算表並**重新整理**，上方會出現「年表」選單。
4. **「年表 → 初次設定」**。第一次會要求授權：選帳號 →（若出現「這個應用程式未經驗證」）點「進階」→「前往…」→「允許」。授權後**再點一次**「初次設定」，詢問公開檢視時選「是」。
5. **（選用）「年表 → 指定附件資料夾」**：想把檔案存進現有的資料夾，就貼上那個資料夾的網址。不做這步的話，會自動使用新建立的「年表附件」資料夾。
6. **「年表 → 設定表單密語」**：自訂一組至少 6 個字的密語。
7. **部署表單網址**：「擴充功能 → Apps Script」→ 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」→
   - 執行身分：**我**
   - 誰可以存取：**任何擁有 Google 帳戶的使用者**
   → 按「部署」。
8. 回試算表「年表 → 表單網址」，複製網址。
9. 交付三樣東西：
   - **表單網址＋密語** → 給要上傳的人
   - **這份試算表的網址** → 給網站維護者（填入網站設定）

授權內容：讀寫這份試算表、在擁有者的雲端硬碟建立資料夾與檔案。程式只在擁有者的帳號內執行。

日後若更換 `Code.gs` 或 `Form.html`：Apps Script →「部署 → 管理部署作業」→ 鉛筆 → 版本選「新版本」→ 部署。網址不變。

## 上傳的人

1. 開啟表單網址（需登入任一 Google 帳號）。
2. 輸入**通關密語**與你的名字（這台裝置會記住）。
3. 上方選「新增附件」或「新增事件」。

**新增附件**

1. 搜尋並點選事件。
2. 選種類。
3. 填標題，然後：
   - **照片／剪報／錄音**：選檔案（30MB 以內）。
   - **影片**：先上傳到 YouTube（可設「不公開」），貼上連結。影片檔很大，放雲端硬碟會很快用完容量，建議一律用 YouTube。
   - **文字**：直接輸入。
4. 按「加入年表」。重新整理年表網站即可看到。

超過 30MB 的錄音：請擁有者把檔案放進附件資料夾並設成「知道連結的任何人都可以檢視」，再在表單展開「改貼連結」貼上。

**新增事件**：選類型、填日期（`1984-12-17`、`1984-12` 或 `1984`）、標題與說明。送出後可以直接「為這件事件加附件」。

## 查看與修改（有試算表編輯權的人）

- 「附件」分頁：一列就是一個展出項目，「填寫人」欄記錄是誰加的。可以直接改標題、圖說、逐字稿。
- 暫時下架：把「顯示」改成「否」。
- 一個附件掛在多件事件：在「事件編號」用逗號分隔，例如 `l3, n87`。
- 「事件」分頁：可以改事件文字，或在最下面新增一列（編號自訂、不可重複，只用英文字母與數字）。
- 逐字稿寫法：一行一段，開頭寫時間，例如 `1:20 這一段的內容`；需要對照翻譯時寫 `1:20 原文 | 中文對照`。
- 「年表 → 檢查資料」會列出填錯的地方。網站會自動略過有問題的列，不會壞掉。

## 注意

- 試算表與附件資料夾是公開可檢視的，**不要放不能公開的內容或內部備註**。
- 附件資料夾裡的檔案**不要移到垃圾桶或取消分享**，否則網站會讀不到。
- 請不要更改兩個分頁的名稱（「事件」「附件」）與第一列的欄位名稱。欄位順序可以調整，也可以在最右邊自行加欄。
- 密語外流時，擁有者用「年表 → 設定表單密語」重設即可。
- 雲端硬碟偶爾會擋下外部網站直接播放錄音；這時網站會自動改用 Google 的播放器，仍可收聽，但無法調速與點逐字稿跳轉。
- 一般 Gmail 的免費容量是 15GB，與信箱、相簿共用。
